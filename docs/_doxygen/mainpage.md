# XMPL100 Driver API reference {#mainpage}

The classes, types and registers of the XMPL100 driver, generated from the headers in `inc/`.

Start with xmpl100::XMPL100, the driver, and xmpl100::SpiInterface, the base of the port you write. Errors are
xmpl100::Error inside xmpl100::Result; the configuration is xmpl100::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">XMPL100 Driver
documentation</a>.
